# 本地定制模块

这里集中保存 qqbridge 魔改版的规则、运行时和控制台扩展。模块不会自行启动桥接、连接 QQ、修改服务器配置或运行安装脚本。

| 目录 | 职责 |
| --- | --- |
| `policy/` | 峰谷时间判定、群聊权限矩阵、定时总开关和参数校验 |
| `runtime/group-chat.js` | 每个桥接实例独立的群聊窗口、冷却、观察、取消和发送检查 |
| `runtime/control-settings.js` | 原 `/api/control-settings` 接口与配置保存契约 |
| `runtime/console-gateway.js` | 回环代理、HTTPS 来源、网关密钥与跨站检查 |
| `runtime/preset-sync.js` | DSH bundle 与旧版目录预设的同步适配 |
| `console/` | 控制台定制片段、锚点清单和页面组合器 |
| `upgrade/` | 生成的独立补丁包：应用工具、补丁、校验清单和模块副本 |
| `upgrade-runner.mjs` | 补丁应用工具的维护源文件 |

`src/` 中四个原有规则文件保留为兼容转发入口，因此旧导入路径不需要修改。桥接主文件通过显式传入的配置、时钟、状态与服务函数连接模块；模块不依靠修改全局变量或运行时替换上游函数。

控制台的 `public/console.html` 已恢复为上游基线原文。HTTP 返回前，组合器按独立锚点清单插入开关页面等定制内容。本次组合结果与重构前页面逐字一致。上游布局变化导致锚点丢失或重复时会报错，需要适配片段，不能默默插到错误位置。

`upgrade/` 是生成产物，修改规则时先修改上面的维护源文件，然后重新构建；不要只修改补丁包中的副本。完整说明见 [模块与剩余接入点](../docs/CUSTOMIZATIONS.md) 和 [升级操作](../docs/UPSTREAM_UPGRADE.md)。
