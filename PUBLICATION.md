# Publication scope

This source-only repository was exported from a local customization snapshot.
Personal account identifiers were removed before creating this repository's history.
It does not include the original private Git commits, actual configuration, role cards,
chat state, credentials, installed dependencies, or complete deployment archives.

The maintainer keeps the original local working repository separately. Future public
releases should be generated and reviewed from that private source, not pushed with
its complete history. Regenerate the checked upgrade bundle after sanitization and
run the regression and privacy checks before publishing.

See README.md, LICENSE, NOTICE and THIRD_PARTY_NOTICES.md for scope and attribution.
